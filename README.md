A single deadpan one-liner, generated by a tiny deterministic program: a therapy joke whose punchline demonstrates the very deflection it names.

## Run it

```sh
python3 main.py
```

It writes one line of comedy (100 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
